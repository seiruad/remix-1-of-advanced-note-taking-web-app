# Умные подсказки в абзацах

Сейчас каждый абзац рендерит редактор с одним и тем же текстом-подсказкой «Start writing your note...», независимо от того, есть ли в абзаце файлы. Отсюда все три проблемы со скриншота.

## Что меняем

1. Абзац с файлами, но без текста
   - Подсказка не показывается вообще. Строка редактора схлопывается (высота 0), остаются только чипы вложений.
   - Текст можно добавить через меню «три точки» → новый пункт «Add Text»: он раскрывает поле и ставит в него курсор. Клик по пустой области абзаца тоже раскрывает поле.

2. Полностью пустой абзац
   - Одна строка-подсказка, предлагающая оба действия: «Write text or attach a file». Слово-действие «attach a file» кликабельно и открывает тот же диалог вложений, что и пункт меню «Attach File»; клик по остальной части ставит курсор в текст.

3. Абзац с текстом — без изменений.

4. Подсказка исчезает, как только в абзаце появляется текст, и не возвращается, пока абзац не станет снова пустым.

## Технически

- `RichTextEditor`: сделать текст подсказки настраиваемым пропом `placeholder` и разрешить пустое значение (подсказка отключается), сохранив текущее поведение по умолчанию.
- `ParagraphBlock`: вычислять состояние абзаца через уже существующий `isDocEmpty` (из `useNoteParagraphs`) + наличие `files`:
  - empty + files → placeholder off, редактор скрыт до раскрытия (локальный стейт `showText`), клик по зоне абзаца раскрывает.
  - empty + no files → своя строка-подсказка с двумя действиями поверх/вместо placeholder tiptap.
  - non-empty → как сейчас.
- В `items` меню добавить пункт «Add Text» (иконка `Type`), видимый только когда текст скрыт.
- Стили — существующие токены (`text-slate-500`, hover `text-slate-300`), без новых цветов. Ничего в БД и логике сохранения не меняется.
