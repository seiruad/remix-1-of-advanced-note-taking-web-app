# Улучшение пустого абзаца: две подписанные кнопки и корректные отступы

## Проблема
Текущий вариант подсказки для пустого абзаца — «Write text or» + иконка скрепки — выглядит не сбалансированно: текстовая часть остаётся текстом, а скрепка — просто иконкой, без подписи. На мобильном устройстве кнопка скрепки прижимается к границе абзаца.

## Цель
Сделать пустой абзац максимально понятным и удобным для касания: оба действия (текст и файл) представлены одинаково — иконка + короткая подпись, с союзом «or» посередине, с читаемой типографикой и без прилипания к краям.

## Что изменим

### 1. Две равноправные кнопки
Вместо текстовой фразы «Write text or» и одинокой скрепки покажем:

- **Слева**: иконка `Type` + подпись «Text»  
  Действие: фокусирует/раскрывает редактор абзаца (аналог «Add Text» в меню).
- **Посередине**: союз «or»  
  Проверить и зафиксировать размер и стиль: `text-sm` на мобильном, `text-[13px]` на десктопе, `text-slate-500`, без жирности.
- **Справа**: иконка `Paperclip` + подпись «Attach»  
  Действие: открывает диалог прикрепления файла.

### 2. Мобильный First-макет
- Расположить три элемента в одну строку по центру абзаца.
- Каждая кнопка — минимум 44×44 px touch target (`min-w-11 min-h-11`).
- Между кнопкой и границей абзаца оставить внутренний отступ не менее `px-3`/`py-2`, чтобы hover/focus-область не касалась края.
- На десктопе уменьшить до компактных `min-w-9 min-h-9` с подписями.

### 3. Стилистика в рамках UnifiedSidebar / StoragePage
- Иконки и подписи: `text-slate-400` в покое, `text-emerald-400` при hover/focus.
- Фон кнопок прозрачный; hover-фон — `bg-slate-700/30` (как у чипов вложений).
- `focus-visible:ring-2 focus-visible:ring-emerald-500/40`.

### 4. Поведение остаётся прежним
- Клик по «Text» раскрывает редактор и ставит фокус.
- Клик по «Attach» вызывает `onAttach`.
- Если пользователь ничего не ввёл и убрал фокус, текстовая область снова сворачивается, а кнопки остаются.
- `aria-label` сохраняется для доступности.
