# План: перекомпоновка UnifiedSidebar (Вариант A + Search в шапке + вечный «No Folder»)

Меняем только `src/components/UnifiedSidebar.tsx` (плюс, при необходимости, лёгкая правка списка папок, если фильтрация «No Folder» живёт там же). Логика создания/переименования/удаления не трогается — переезжают только точки входа.

## 1. Workspace-header — добавить иконку поиска

Справа от имени воркспейса — компактная иконка 🔎 (36×36, ghost). По тапу:
- строка поиска раскрывается **под** Workspace-header, поверх nav-row (как сейчас на мобиле), с автофокусом;
- крестик закрывает и очищает запрос;
- Esc / пустой blur — сворачивает обратно в иконку.

Контекст поиска сохраняется прежним:
- All Notes → все заметки;
- Folders (список) → имена папок;
- Внутри папки → заметки этой папки;
- 0 результатов вне All Notes → шорткат «Search all notes instead».

Клик по самой шапке (управление воркспейсом) не конфликтует: иконка поиска — отдельная кнопка со `stopPropagation`.

## 2. Nav-row — только навигация

Оставляем **один** элемент на всю ширину: сегментированный тогл `All Notes | Folders`. Убираются:
- поле/иконка поиска (уехали в шапку);
- кнопка `+ New` (уезжает в FAB, см. п. 4).

Высота ряда та же (h-11), тогл растягивается на всю ширину — становится крупной, thumb-friendly целью на мобиле.

## 3. Folder-context-strip — только информация

Полоска внутри папки остаётся, но действий в ней нет:
- `‹` back (уже принятый Native mobile fluid стиль) — оставляем, это навигация, а не действие;
- цветной dot + имя папки + счётчик;
- `⋯` меню (Rename / Delete) — это управление сущностью «папка», не создание, поэтому остаётся здесь.

Создание заметки внутри папки — через FAB (п. 4).

## 4. FAB — единая точка создания

Плавающая круглая кнопка в правом-нижнем углу сайдбара (`absolute bottom-4 right-4`, над блоком STORAGE, `z-20`), 56×56, тот же emerald-градиент, что у текущей «+», с glow.

Поведение по контексту:
- **All Notes** → тап = создать заметку;
- **Folders (список)** → тап открывает мини-меню над FAB: `📄 New Note` / `📁 New Folder`
  - `New Note` → создаёт заметку без папки и открывает «No Folder» с этой заметкой сверху (текущая логика);
  - `New Folder` → создаёт новую папку (текущая логика, is_new подсветка);
- **Внутри папки** → тап = создать заметку, сразу привязанную к текущей папке.

Иконка/подпись FAB меняется по контексту (`+`, `+ ▾`, `+`), цвет — единый emerald для консистентности (амбер/слейт-варианты уходят, чтобы не спорить с индикаторами папок).

FAB скрывается, когда открыт поиск с непустым запросом (не мешать чтению результатов).

## 5. «No Folder» — всегда в списке

В рендере списка папок «No Folder» пин-строкой сверху **всегда**, даже когда `unfiledCount === 0`. Стиль — прежний slate/dashed. Счётчик показывает `0`, строка кликабельна и ведёт в пустое состояние «No unfiled notes yet» с подсказкой создать заметку через FAB.

Поиск по именам папок в режиме списка «No Folder» из выдачи не выкидывает (закреплён сверху вне зависимости от query) — либо, если это выглядит шумно, показываем его только при пустом query. Финальное поведение при поиске уточним по ходу реализации; дефолт — всегда виден.

## Итоговая структура сайдбара сверху вниз

```text
┌─────────────────────────────────────┐
│ Workspace  ▾            🔎          │  ← + поиск-иконка
├─────────────────────────────────────┤
│ [ All Notes | Folders ]             │  ← только навигация
├─────────────────────────────────────┤
│ ‹  ● Folder name   3          ⋯     │  ← только внутри папки
├─────────────────────────────────────┤
│                                     │
│  список заметок / папок             │
│  (No Folder всегда сверху)          │
│                                     │
│                              ╭───╮  │
│                              │ + │  │  ← FAB
│                              ╰───╯  │
├─────────────────────────────────────┤
│ STORAGE …                           │
└─────────────────────────────────────┘
```

## Технические детали

- `UnifiedSidebar.tsx`:
  - Workspace-header: добавить кнопку `SearchIcon`, `stopPropagation`, состояние `searchOpen` поднять на уровень сайдбара (сейчас живёт в nav-row).
  - Nav-row: удалить search-swap и `+`-кнопку, оставить только `SegmentedToggle` full-width.
  - `FolderContextStrip`: удалить любые action-кнопки создания (если появлялись), оставить back + info + `⋯`.
  - Новый компонент `SidebarFab` с пропсами `mode`, `onCreateNote`, `onCreateFolder`; меню — тот же паттерн, что уже есть у `+`-кнопки (`useFloating`/portal, как в текущем коде).
  - Список папок: снять условие `unfiledCount > 0` для `No Folder`-строки; в пустом состоянии внутри «No Folder» показать плейсхолдер.
- Никаких изменений в БД, роутинге, edge-функциях, типах.

## Что НЕ делаем

- Не трогаем стили карточек заметок и папок (кроме плейсхолдера пустой «No Folder»).
- Не меняем логику создания/переименования/удаления.
- Не убираем folder-context-strip и back-кнопку — это принятый Native mobile fluid.
