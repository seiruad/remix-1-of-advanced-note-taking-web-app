# Редактор заметок: абзацы с вложениями

Текст заметки перестаёт быть одним сплошным документом и превращается в список абзацев. Каждый абзац — это текст плюс свои вложения, у каждого абзаца своё меню управления.

## Структура абзаца

```text
┌───────────────────────────────────────────┐
│ [текст абзаца — редактируемый]        ⋯  │
│ ─────────────────────────────────────────│
│ [📄 report.pdf ×] [🖼 photo.png ×]        │
└───────────────────────────────────────────┘
```

- Абзац существует, если в нём есть текст ИЛИ хотя бы одно вложение. Пустые абзацы без вложений удаляются автоматически при потере фокуса.
- Вложения всегда идут после текста, компактными чипами: иконка по типу файла + укороченное имя (обрезка по ширине, а не жёсткое число символов). Тап по чипу — предпросмотр (существующий FilePreviewModal). Крестик/меню чипа — «Отвязать от абзаца» (файл остаётся привязан к заметке и виден в нижней панели вложений).

## Меню абзаца (⋯, UnifiedMenu)

1. Добавить абзац выше
2. Добавить абзац ниже
3. Прикрепить файл к абзацу (выбор из вложений заметки + загрузка нового)
4. Слить с другим абзацем
5. Удалить абзац (через UnifiedWarningWindow)

**Режим слияния:** после выбора «Слить с другим абзацем» сверху появляется тонкая подсказка-полоска «Выберите абзац» с кнопкой отмены, остальные абзацы подсвечиваются как кликабельные. По тапу на целевой абзац появляется маленькое всплывающее меню: «Добавить сверху», «Добавить снизу», «Отмена». Текст и вложения исходного абзаца переносятся в целевой в выбранном порядке, исходный абзац удаляется. Esc / тап мимо — выход из режима.

## Нижняя панель вложений

Остаётся как есть (общий список файлов заметки + кнопка Attach). Файл, загруженный оттуда, привязан к заметке, но не к абзацу. Файл, прикреплённый к абзацу, тоже появляется в общем списке.

## Данные

- Новая таблица `note_paragraphs`: `id`, `note_id`, `user_id`, `position` (int), `content` (jsonb, Tiptap-документ абзаца), `created_at`, `updated_at`. RLS + GRANT по образцу `notes`/`note_files` (владелец через `auth.uid()`, плюс чтение/правка для расшаренных заметок аналогично политикам `notes`).
- В `note_files` добавляется nullable `paragraph_id` → `note_paragraphs.id` (`on delete set null`), это и есть привязка вложения к абзацу.
- Миграция существующих заметок: при первом открытии заметки без абзацев её текущий `notes.content` превращается в один абзац с `position = 0`. `notes.content` сохраняется как есть и больше не редактируется.

## Компоненты

- `src/components/paragraphs/ParagraphList.tsx` — загрузка/сохранение абзацев, порядок, вставка/удаление/слияние, режим слияния, дебаунс-автосейв (как сейчас 600 мс).
- `src/components/paragraphs/ParagraphBlock.tsx` — один абзац: RichTextEditor + меню + строка вложений.
- `src/components/paragraphs/ParagraphAttachments.tsx` + `AttachmentChip.tsx` — чипы вложений, предпросмотр, отвязка.
- `src/components/paragraphs/useNoteParagraphs.ts` — вся работа с БД (CRUD, перестановки, привязка файлов).
- `NoteEditor.tsx` рендерит `ParagraphList` вместо одиночного `RichTextEditor`; тулбар форматирования работает с активным (сфокусированным) абзацем.

## Дизайн

Mobile First, стилистика UnifiedSidebar / StoragePage: слейт-стекло (`bg-slate-800/60`, границы `slate-700/50`), изумрудный акцент для активного абзаца и кнопок, янтарный для нового, `rounded-xl`, крупные тач-таргеты (кнопка ⋯ 36–40 px на мобиле), чипы вложений в одну прокручиваемую строку с переносом. Меню — существующий `UnifiedMenu`, подтверждение удаления — `UnifiedWarningWindow`.

## Порядок работ

1. Миграция БД (`note_paragraphs`, `paragraph_id`, RLS, GRANT).
2. Хук `useNoteParagraphs` + автоконвертация старого контента.
3. `ParagraphBlock` + меню + удаление/вставка.
4. Вложения абзаца (чипы, предпросмотр, отвязка, прикрепление).
5. Режим слияния.
6. Стилевая доводка под мобильные экраны и проверка в превью.
