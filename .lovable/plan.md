# Плавная верхняя панель без дёрганья

## Что происходит сейчас

В `SidebarNavBar` три слота анимируются по-разному:

- кнопки «All Notes» и «Folders» переключаются между `flex-1` и `w-10` — ширина меняется **мгновенно** (transition стоит только на цвете);
- бейдж папки анимируется 150 мс через `opacity` + `max-w-0 → max-w-full`;
- содержимое кнопок подменяется (иконка+текст ↔ одна иконка), что даёт дополнительный реflow в тот же кадр.

Итог: ширины прыгают скачком, а бейдж «догоняет» их с задержкой — визуально панель дёргается.

## Решение

Одна анимируемая величина на всю панель вместо трёх независимых.

1. Контейнер сегментов делаем CSS-grid из трёх колонок и анимируем только `grid-template-columns`:
   - снаружи папки: `1fr 1fr 0fr`
   - внутри папки: `2.5rem 2.5rem 1fr`
   Все три слота двигаются одним и тем же переходом, в обе стороны одинаково.
2. Содержимое каждой кнопки не подменяется условно, а рендерится всегда: иконка «All Notes» / «Folders» + подпись, поверх — иконки-стрелки (`ChevronsLeft`, `ChevronLeft`). Переключение между ними — кроссфейд по `opacity` в том же тайминге, без изменения потока.
3. Бейдж папки остаётся всегда в DOM, но теряет `max-width`-анимацию: его ширину задаёт колонка грида, остаётся только `opacity` для мягкого проявления.
4. Единый тайминг для всех переходов: `200ms cubic-bezier(0.4, 0, 0.2, 1)`; убираем `will-change-transform` (transform не анимируется) и оставшиеся `transition-colors` приводим к тому же тайму.

## Технические детали

- Файл: `src/components/UnifiedSidebar.tsx`, компонент `SidebarNavBar` (строки ~125–220).
- Слоты внутри грида получают `overflow-hidden min-w-0`, чтобы текст обрезался при сжатии колонки, а не выталкивал её.
- Кроссфейд иконок — через `relative` кнопку и два `absolute inset-0 flex` слоя с `opacity-0/100` и `pointer-events-none` у скрытого.
- Проверка: `tsgo` + Playwright-скрипт с покадровыми снимками входа в папку и обоих возвратов (в список папок и в All Notes) — длительность и траектория должны совпадать.
