# Верхняя панель из 3 бейджей + кнопка меню папки рядом с New Note

Убираем отдельную полосу-«навес» с названием папки. Внутри папки верхняя панель превращается в три компактных бейджа, а управление папкой уезжает вниз рядом с `New Note`.

## Как это выглядит

Верхняя строка (h-11), mobile-first:

```text
вне папки:   [ ▤ All Notes ][ ⌸ Folders ]
внутри:      [ ▤ ][ ⌸〈 ][ ● Library ]
```

1. **All Notes** — иконка `LayoutList` без текста, квадратная кнопка (~36×36). Тап переключает в режим All Notes.
2. **Folders / назад** — иконка, совмещающая папку и возврат. Вариант: `FolderInput` (папка со стрелкой влево) или `ChevronLeft` поверх/рядом с `Folder`. Кнопка чуть крупнее первой (~40×36 или шире по горизонтали). Тап — возврат к списку папок.
3. **Название папки** — текстовый бейдж-лейбл (не кнопка действия), с цветной точкой слева: обычная папка — emerald, новая — amber (+ мини-бейдж New, если влезает), «No Folder» — slate + italic. Название truncate, занимает оставшееся место.

Нижняя панель:

```text
[      + New Note      ][ ⋯ ]
```

- `New Note` — по-прежнему основная кнопка внизу, но уже не на всю ширину: прижата к левому краю и занимает ~75–80% ширины.
- Справа от неё — квадратная кнопка `⋯` (36–44px), открывающая `UnifiedMenu` с Rename / Delete для текущей папки.
- Оба элемента выровнены по нижнему краю, с одинаковой высотой и радиусом/стилем как у текущей кнопки `New Note`.

## Mobile-first детали

- Верхняя строка 44px, все тач-таргеты не меньше 36px.
- Бейджи визуально отделены, но вписаны в единый `bg-slate-900/60` контейнер с `rounded-lg`.
- Активный/нажатый бейдж — `bg-slate-700`, как сейчас активный сегмент.
- Название папки — `bg-slate-700` или `bg-slate-800/60`, чтобы выглядеть как информация, а не как действие; цвет текста `text-slate-100`.
- Нижняя кнопка `New Note` сохраняет текущий зелёный стиль, но ширина `flex-[3]`; кнопка `⋯` — `flex-1` или фиксированная ~44px, та же высота, `bg-slate-700/60`/`hover:bg-slate-700`, иконка `MoreVertical`.

## Технически

Правки в `src/components/UnifiedSidebar.tsx`, компонент `SidebarNavBar`:
- Удалить блок «folder context strip» (`insideFolder && crumbInfo`).
- При `mode === 'folders' && selectedFolderId` рендерить три бейджа вместо двух сегментов.
- `All Notes` бейдж вызывает `switchToAllNotes()`.
- `Folders/назад` бейдж вызывает `setSelectedFolderId(null)`.
- Бейдж названия папки — неинтерактивный, использует `crumbInfo`.
- Rename остаётся возможным, но теперь через меню внизу: тап `⋯` → Rename открывает `UnifiedWarningWindow`-подобный диалог или инлайн-редактирование. Для простоты — открывать маленький bottom-sheet/диалог с полем переименования, либо переключать бейдж названия в инлайн-инпут.

Управление папкой внизу:
- В `SidebarFab` или рядом с ним добавить кнопку `⋯`, видимую только внутри папки (`mode === 'folders' && selectedFolderId`).
- Кнопка вызывает `UnifiedMenu` с Rename / Delete; Delete — через `UnifiedWarningWindow`.

Бизнес-логика, создание заметок, поиск и списки не трогаются.
