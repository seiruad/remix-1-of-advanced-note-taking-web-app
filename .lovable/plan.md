# Контекст папки — в верхнюю панель UnifiedSidebar

Убираем отдельную полосу-«навес» с названием папки. Внутри папки верхняя панель целиком превращается в панель контекста: слева — «назад», справа — папка с меню.

## Как это выглядит

Одна строка (h-11), как сейчас, mobile-first:

```text
вне папки:   [ ▤ All Notes ][ ⌸ Folders ]
внутри:      [ ‹ Folders  ][ ● Library   2   ⋯ ]
```

- Левый сегмент на месте `All Notes` становится кнопкой «назад»: `‹ Folders`. Тап — возврат к списку папок, где снова доступны обе вкладки `All Notes` / `Folders`.
- Правый сегмент — активный контекст папки: цветная точка, название (truncate), счётчик заметок, `⋯` (Rename / Delete через `UnifiedMenu`).
- Rename открывает инлайн-инпут прямо в сегменте (как сейчас в полосе), Escape отменяет.
- Цвета по типу папки: обычная — emerald, новая — amber (+ бейдж New, если хватает места), «No Folder» — slate, курсив, без меню.
- Вторая строка исчезает: список заметок начинается сразу под панелью, экран выше на ~44px.
- Нижняя кнопка `New Note` не меняется.

Компромисс: внутри папки прямой кнопки `All Notes` нет — один тап «назад» возвращает к переключателю. Это осознанный размен ради незагруженной панели на 360px.

## Mobile-first детали

- Высота строки 44px, тач-таргеты `‹` и `⋯` не меньше 36×36.
- Название — единственный гибкий элемент (`flex-1 min-w-0 truncate`), счётчик и `⋯` фиксированной ширины, чтобы длинные имена не ломали строку.
- Токены как в остальном сайдбаре: контейнер `bg-slate-900/60`, активный сегмент `bg-slate-700`, текст emerald-400, ховеры `hover:bg-slate-700/60`, `active:scale-95`.

## Технически

Правки только в `src/components/UnifiedSidebar.tsx`, компонент `SidebarNavBar`:
- Удалить блок «folder context strip» (`insideFolder && crumbInfo`).
- В контейнере сегментов при `mode === 'folders' && selectedFolderId` рендерить два новых сегмента: кнопку «назад» (`setSelectedFolderId(null)`) вместо `All Notes` и контекст-сегмент папки вместо `Folders`.
- Существующие `isRenaming` / `renameValue`, `crumbInfo` и `UnifiedMenu` (Rename, Delete) переносятся в контекст-сегмент; `onRenameFolder` / `onOpenDeleteFolder` не меняются.
- Вне папки поведение сегментов остаётся прежним.

Бизнес-логика, создание заметок, поиск и списки не трогаются.
