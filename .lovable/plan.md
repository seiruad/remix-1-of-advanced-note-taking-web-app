# План: Редизайн Workspace-блока в UnifiedSidebar

Задача — три изменения в шапке сайдбара (`src/components/UnifiedSidebar.tsx`, ~строки 1272–1335). Никакой другой логики не трогаем.

## 1. Клик и переход на страницу Workspaces

Сейчас вся левая половина шапки — одна большая кнопка `onOpenWorkspaceManagement` + иконка `Settings2` справа. Тап-зона огромная, но неочевидно, что это переход на _список workspaces_, а не «настройки».

Меняем так:
- Кликабельная зона — только область «иконка + Workspace / My Workspace» (компактная, по ширине контента, не растягивается).
- Справа от названия — маленький `ChevronRight` (12 px, `text-slate-500`), а не `Settings2`. Это визуальный сигнал «перейти к списку workspaces», а не «открыть настройки».
- `aria-label="Switch workspace"`, `title="Switch workspace"`.
- Иконку `Settings2` убираем из шапки полностью (настройки живут в своём месте, не в шапке).

## 2. Внешний вид блока (соответствие остальному сайдбару)

Приводим шапку к тем же токенам, что и остальной обновлённый сайдбар:

- Высота — фиксированная `h-14` (56 px), как договаривались в предыдущем ритме. Убираем `pt-4 pb-3`.
- Фон — `bg-slate-800` (surface-1), нижний бордер `border-slate-700/50` — уже так, оставляем.
- Иконка Workspace — оставляем `w-9 h-9 rounded-lg bg-emerald-500/15` с `Notebook` (уже унифицирована).
- Типографика:
  - Метка `Workspace` — `text-[10px] uppercase tracking-wider text-slate-500` — оставляем.
  - Имя — `text-sm font-semibold text-slate-100` (было `font-bold text-white` — слишком тяжело для 56-px полосы).
- Кнопка поиска (справа) — `w-9 h-9 rounded-lg`, ghost-стиль как у остальных action-кнопок. Активное состояние (поиск открыт) — `bg-emerald-500/15 text-emerald-300`, уже так. Оставляем.
- Hover области Workspace-кнопки — `hover:bg-slate-700/40 rounded-lg`, чтобы совпадало с hover’ом NoteCard/строк.

## 3. Поиск внутри Workspace-блока (не отдельная полоса ниже)

Сейчас: тап по 🔍 → под шапкой появляется отдельная полоса `h-11` с input + Cancel. Это ломает ритм и делает шапку «двухэтажной».

Меняем на **in-place swap внутри самой шапки**:

- В обычном режиме шапка = `[иконка] [Workspace / My Workspace ›] ...................... [🔍]`.
- При `searchOpen = true` содержимое шапки **заменяется** на: `[🔍 внутри input] [__input во всю ширину__] [Cancel]`. Никакой второй полосы не появляется. Высота остаётся `h-14`.
- Input — `h-9 bg-slate-900/60 rounded-lg`, автофокус (уже есть `searchInputRef`), плейсхолдер контекстный (`searchPlaceholder`, уже вычисляется).
- Кнопка `Cancel` — текстовая, `h-9 px-2.5 rounded-lg`, справа. По клику — очищает query и закрывает поиск.
- `Escape` в инпуте — тоже закрывает (уже реализовано).
- Блок `{searchOpen && (<div className="h-11 ...">...</div>)}` (строки 1305–1335) удаляем полностью — поиск живёт _внутри_ шапки.

Визуально это даёт то же поведение, что iOS Notes / Mail: тап по 🔍 «раскрывает» поиск прямо в шапке, шапка не растёт по высоте, ничего не появляется ниже.
