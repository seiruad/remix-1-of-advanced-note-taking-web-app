## Location‑bar: переосмысленный header папки (mobile‑first)

Идея: не «микро‑строка с ярлычком», а **location bar** — небольшой, но дышащий индикатор «ты здесь», с крупным именем папки и настоящими тап‑таргетами 40×40.

### Что не так сейчас

- Uppercase‑лейбл `FOLDER` + `·` + имя + `·` + число в одной 9‑пиксельной строке → каша.
- Полоса высотой ~32px с иконками 24px — визуально «тонкая», но неинтерактивная: тап‑таргеты `w-7 h-7` (28px) меньше рекомендации Apple/Google 44px.
- Левый акцент шириной 2px и `-mx-3` не читается на мобильном.
- Нет иерархии: имя папки и служебный лейбл одного размера/веса.

### Новый layout (одна строка, но с воздухом)

```text
┌──────────────────────────────────────────────────┐
│  ←     [ 📁 ]   E4A                    3    ⋯   │
│ 40×40   32       16px semibold     pill  40×40   │
└──────────────────────────────────────────────────┘
        ↑ tinted square, matches variant
```

- Высота **56px** (`h-14`), паддинги `px-2`, gap `gap-2`.
- **Sticky** сверху скролл‑контейнера (`sticky top-0 z-20`), `backdrop-blur`, `-mx-3` — на всю ширину сайдбара.
- Тонкая нижняя граница (variant‑цвет, `border-b`) вместо вертикальной полоски слева — визуально как таб‑бар, читается на любой ширине.
- **Back**: `w-10 h-10` ghost‑кнопка, `ChevronLeft` 20px, `aria-label="Back to folders"`.
- **Icon plate**: `w-8 h-8` rounded‑lg, тинтованный фон по варианту, иконка 16px.
- **Имя папки**: `text-base font-semibold` (16px), `truncate`, забирает весь `flex-1`. Крупно и понятно.
- **Счётчик**: маленькая пилюля справа от имени — `text-[11px] tabular-nums px-1.5 py-0.5 rounded-full` в цвет варианта (напр. `bg-emerald-500/15 text-emerald-300`). Только число, без слова.
- **Menu ⋯**: `w-10 h-10` ghost‑кнопка. Не показывается для `No Folder`.
- Убираем uppercase‑лейбл `FOLDER` — иконка + цвет уже говорят это.

### Три варианта (сохраняем цветовое кодирование)

| Вариант   | Иконка       | Тинт плитки/пилюли | Bottom border          |
|-----------|--------------|--------------------|------------------------|
| Обычная   | `FolderOpen` | emerald‑500/15     | solid emerald‑500/25   |
| Новая     | `FolderPlus` | amber‑500/15       | solid amber‑500/30 + маленький бейдж `NEW` (amber pill 9px) слева от счётчика |
| No Folder | `Inbox`      | slate‑500/20       | **dashed** slate‑500/40, имя пишем как «No Folder» без счётчика‑пилюли (используем нейтральный `text-slate-500`) |

Для «No Folder»: убираем меню (нельзя переименовать/удалить виртуальную папку), счётчик рендерим нейтральным серым, чтобы визуально отличалось от «настоящих» папок.

### Rename (inline)

Тап на «⋯ → Rename» превращает имя в input прямо в этой же строке (`h-8`, тот же размер шрифта), не ломая высоту — уже реализовано, оставляем логику, подгоняем стили под новый размер.

### Что меняем в коде

Только `src/components/UnifiedSidebar.tsx`, функция `FolderDetailHeader` (≈ линии 605–787). Пропсы не меняются — `onBack` уже прокидывается. Никаких изменений в списках, action‑row, роутинге, БД.

### Что НЕ меняем

- Action‑row (кнопка «New Note» на всю ширину внутри папки) — остаётся как есть.
- Список папок, карточки заметок, поиск.
- Логика создания/удаления/переименования.

### Проверка

После правки — скриншот на 390×800 (мобилка) внутри обычной папки, «No Folder» и «новой папки», убедиться что:
- header не выше 56px,
- имя читается крупно, счётчик не сливается,
- back/menu легко попадаются пальцем,
- на 1200px десктопа не выглядит перегруженно.
